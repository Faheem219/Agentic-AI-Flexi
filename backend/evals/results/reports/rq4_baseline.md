# Do multi-agent LLM systems outperform single-agent approaches on complex reasoning tasks? (baseline)

Recent research increasingly suggests that multi-agent LLM systems (MAS) significantly outperform single-agent approaches on complex reasoning, coding, and planning tasks. While single-agent setups rely on prompting techniques like Chain-of-Thought (CoT), they often struggle with long-horizon planning and error propagation. In contrast, multi-agent frameworks leverage role-based specialization and iterative collaboration to improve performance [1]. By decomposing complex problems into sub-tasks assigned to specialized agents—such as a coder, reviewer, and planner—MAS can effectively reduce hallucinations and improve code generation accuracy [2]. Frameworks like MetaGPT and ChatDev have demonstrated that allowing agents to simulate software development lifecycles leads to higher-quality outputs compared to monolithic prompts [3, 4]. Furthermore, the collaborative nature of these systems enables self-correction mechanisms; agents can critique each other's outputs, which is a critical advantage over static, single-turn reasoning [5]. Studies on "AgentVerse" highlight that dynamic team formation, where agents are added or removed based on the task requirements, further optimizes resource efficiency and reasoning capabilities [6]. However, this performance gain is not without trade-offs. Multi-agent systems introduce increased computational latency and higher token costs, raising questions about the scalability of these architectures for real-time applications [7]. Despite these challenges, the consensus in the literature is that the modularity and iterative refinement inherent in multi-agent architectures provide a robust solution for tasks that exceed the cognitive capacity of a single LLM instance [8].
